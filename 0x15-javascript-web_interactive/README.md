# 0x15. JavaScript - Web jQuery Part 1

Interactive DOM manipulation with vanilla JavaScript (no jQuery, no external
libraries, no `var`). Nothing reloads the page: every action updates the DOM
in place.

## Tasks

| File | Description |
| --- | --- |
| `0-script.js` | Turns the `<header>` text red (`#FF0000`) |
| `1-script.js` | Turns every `<p>` blue (`#0000FF`) using `querySelectorAll` |
| `2-script.js` | Turns the header red when `DIV#red_header` is clicked |
| `3-script.js` | Adds the class `red` to the header on click with `classList.add()` |
| `4-script.js` | Toggles the header between `red` and `green` on click of `DIV#toggle_header` |
| `5-script.js` | Appends `<li>Item</li>` to `UL.my_list` when `DIV#add_item` is clicked |
| `6-script.js` | Sets the header text to `New Header!!!` when `DIV#update_header` is clicked |

## Usage

Each script is loaded by the matching HTML page from the project description
(`<script type="text/javascript" src="N-script.js"></script>`) and runs in any
modern browser.
