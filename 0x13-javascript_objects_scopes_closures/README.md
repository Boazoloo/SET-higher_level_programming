# JavaScript - Objects, Scopes and Closures

This project covers JavaScript concepts related to objects, classes, constructors, methods, inheritance, scopes, and closures.

## Requirements

* Node.js 14.x
* Ubuntu 20.04 LTS
* Semistandard 16.x
* All JavaScript files must be executable
* All JavaScript files must start with `#!/usr/bin/node`

## Files

* `0-rectangle.js` - Empty Rectangle class
* `1-rectangle.js` - Rectangle class with width and height
* `2-rectangle.js` - Rectangle class with validation
* `3-rectangle.js` - Rectangle class with a print method
* `4-rectangle.js` - Rectangle class with rotate and double methods
* `5-square.js` - Square class inheriting from Rectangle
* `6-square.js` - Square class with custom character printing
